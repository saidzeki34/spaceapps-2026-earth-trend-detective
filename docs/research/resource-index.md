# Research resource index

Prepared 2026-11-13. Reading material only; no solution implementation or dataset processing.

## Provenance and limits

The authoritative list is the [challenge Resources tab](https://www.spaceappschallenge.org/2026/challenges/earth-system-trend-detective/?tab=resources). Direct retrieval returned gateway/service errors during preparation. The 13 links below were recovered from [HackAthlone's local-event copy](https://hackathlone.com/challenges/earth-system-trend-detective), then followed to their providers. **Reconcile this inventory against the official tab when reachable.** Do not claim the list is complete or officially reverified.

Provider pages differ from product documentation. A working landing page does not establish API access, usable coverage, a license, or successful data retrieval. All entries are reviewed/bookmarked references, not sources already used by a finished project. Full articles, tutorial code and datasets have not been copied into this repository.
