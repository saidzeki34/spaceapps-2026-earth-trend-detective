# Submission checklist

Complete once competition work is allowed.

- [ ] Official challenge requirements satisfied and scientific claims validated.
- [ ] README covers installation, usage, demo, and reproduction.
- [ ] Data, transformations, libraries, models, images, and AI assistance credited.
- [ ] Licensing verified; no credentials or private data in history.
- [ ] Public code and working demo accessible to judges.
- [ ] Reviewed `develop` merged into `main`.
- [ ] Official event project page completed and submission made by the applicable deadline.
